حول الأداة وكيفية النشر على GitHub

تطبيق Pro OCR Extractor تم تصميمه ليعمل بالكامل داخل المتصفح (Client-Side) باستخدام تقنية WebAssembly ومحرك Tesseract.js مفتوح المصدر.

🚀 خطوات رفع الصفحة على GitHub لتعمل على الموبايل:

  1. أنشئ مستودعاً جديداً (New Repository) في حسابك على GitHub.com وسمّه مثلاً ocr-app واجعله Public.
  2. اسحب ملفات هذا المجلد (index.html, style.css, app.js, إلخ) وأفلتها في المستودع ثم اضغط Commit changes.
  3. من المستودع، اذهب إلى Settings ➔ Pages.
  4. تحت Branch اختر main ثم اضغط Save.
  5. خلال دقيقة واحدة، سيظهر لك رابط دائم وآمن مثل:
    https://username.github.io/ocr-app افتحه من متصفح الموبايل وستعمل معك بكامل ميزاتها!
